# Organic Chemistry Website

Interactive React and Vite website for exploring SN1, SN2, E1, and E2 reaction mechanisms.

## Live site

https://thanetadisak-hub.github.io/organic-chemistry-website/

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

The site deploys to GitHub Pages from `.github/workflows/deploy.yml` whenever changes are pushed to `main`.
